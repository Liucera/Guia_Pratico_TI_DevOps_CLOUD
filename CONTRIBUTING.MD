# Guia de Contribuição 🤝

Ficamos muito felizes que você queira contribuir para o **Guia Prático de Dev, Cloud e Automação**! Toda contribuição, seja para corrigir um erro de digitação, atualizar um comando que mudou ou adicionar novas dicas, é bem-vinda.

## Como posso contribuir?

### 1. Reportando Bugs ou Sugestões
Se você encontrou algo errado ou tem uma ideia de melhoria, abra uma **Issue**. Descreva claramente o problema ou a sugestão.

### 2. Enviando Mudanças (Pull Requests)
Para contribuir com código ou conteúdo diretamente:
1. Faça um **Fork** do repositório.
2. Crie uma branch para sua modificação:
   ```bash
   git checkout -b feature/minha-melhoria
   ```
3. Faça suas alterações nos arquivos dentro da pasta `capitulos/`.
4. Garanta que a formatação Markdown esteja correta.
5. Faça o commit de suas alterações com uma mensagem clara:
   ```bash
   git commit -m "Adiciona comando X ao capítulo Y"
   ```
6. Envie para o seu fork:
   ```bash
   git push origin feature/minha-melhoria
   ```
7. Abra um **Pull Request** para a branch principal deste repositório.

## Padrões de Conteúdo

- **Simplicidade:** Mantenha as explicações curtas e focadas no comando ou conceito.
- **Formatação:** Use blocos de código para comandos (ex: \`git status\`).
- **Linguagem:** O guia é escrito em **Português do Brasil**.

## Código de Conduta

Seja respeitoso e colaborativo com os outros membros da comunidade.
