# Guia Prático de Dev, Cloud e Automação em 1250 Comandos

Moderna folha de cola (*cheat sheet*) e manual de referência rápida contendo **25 capítulos** e **1250 comandos, conceitos e exercícios práticos**. Projetado estrategicamente para acelerar o fluxo de trabalho diário de desenvolvedores, engenheiros DevOps e profissionais de computação em nuvem.

---

## 🚀 Apresentação

Este guia nasceu da necessidade prática de centralizar, em um único ecossistema, os comandos, atalhos e conceitos que realmente fazem a diferença no dia a dia técnico. Em vez de explicações puramente teóricas ou densas, cada capítulo traz **50 itens objetivos e acionáveis**, ideais para consulta rápida durante deploys, resolução de problemas em sprints ou estudos focados para certificações.

O projeto funciona como um verdadeiro **"canivete suíço" de infraestrutura e desenvolvimento**, cobrindo desde fundamentos essenciais de código e versionamento até arquiteturas complexas multi-cloud e automações de ponta.

## 🗺️ Estrutura do Repositório (Índice de Capítulos)

O conteúdo está modularizado para facilitar a navegação. Clique nos links abaixo para explorar os comandos de cada seção:

### 💻 Módulo 1: Fundamentos de Desenvolvimento e Ambientes Locais
* [**Capítulo 1: HTML**](./capitulos/01-html.md) — Estrutura de páginas web, tags essenciais, atributos, formulários, semântica e estruturação básica de conteúdo para a web.
* [**Capítulo 2: Python**](./capitulos/02-python.md) — Conceitos básicos de programação, tipos de dados, fluxo de controle (if/else, loops), funções, scripts simples e primeiros comandos de execução.
* [**Capítulo 3: Java**](./capitulos/03-java.md) — Sintaxe baseada em classes, tipagem estática, conceitos de orientação a objetos (POO), compilação e execução na JVM.
* [**Capítulo 4: JavaFX**](./capitulos/04-javafx.md) — Criação de interfaces gráficas (GUI) em Java, componentes visuais, gerenciamento de layouts, eventos de clique e ciclo de vida da aplicação.
* [**Capítulo 5: React**](./capitulos/05-react.md) — Componentização de front-end, gerenciamento de estado (hooks como useState e useEffect), renderização dinâmica e consumo de APIs no ecossistema JavaScript.

### 🌐 Módulo 2: APIs, Versionamento e Ambientes Linux
* [**Capítulo 6: FastAPI**](./capitulos/06-fastapi.md) — Conceitos de HTTP, métodos REST, códigos de status, uso de curl, ferramentas de teste de API e automação básica.
* [**Capítulo 7: Git e GitHub**](./capitulos/07-git-github.md) — Comandos essenciais, fluxos locais, gerenciamento avançado (push/pull/fetch), branches remotas, pull requests, rebase interativo, reflog e estratégias avançadas de workflow.
* [**Capítulo 8: Docker**](./capitulos/08-docker.md) — Imagens, containers, Dockerfile, volumes, redes e orquestração local de múltiplos serviços utilizando múltiplos containers através do Docker Compose (App + DB + Cache).
* [**Capítulo 9: WSL**](./capitulos/09-wsl.md) — Instalação e configuração do WSL, integração com Windows Terminal, acesso cruzado de arquivos e boas práticas.
* [**Capítulo 10: Linux**](./capitulos/10-linux.md) — Navegação, manipulação de arquivos, permissões, processos, redirecionamento, pipes e scripts bash básicos.

## 🛠️ Como Utilizar este Guia

1. **Consulta Rápida:** Use a barra de pesquisa do GitHub (`Ctrl + F` ou `Cmd + F`) dentro dos capítulos para localizar o comando exato de que precisa (ex: `docker build` ou `git reflog`).
2. **Estudo Dirigido:** Siga a ordem sequencial dos capítulos para construir uma trilha sólida de aprendizado, indo do código local até a orquestração na nuvem.
3. **Prática Dinâmica:** Vá direto ao bloco final de exercícios práticos integrados para testar os seus conhecimentos em cenários que simulam o ambiente real do mercado.
