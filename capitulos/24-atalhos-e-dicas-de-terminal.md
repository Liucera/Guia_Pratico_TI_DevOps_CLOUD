## 24 Atalhos e dicas de Terminal

1. `Tab`: completa automaticamente comandos, nomes de arquivos e diretórios, economizando digitação e evitando erros.

2. `Ctrl-A`: move o cursor para o início da linha, permitindo editar o começo do comando rapidamente.

3. `Ctrl-E`: move o cursor para o fim da linha, útil para adicionar algo ao final do comando.

4. `Ctrl-B`: move o cursor um caractere para trás, permitindo navegação fina no texto.

5. `Ctrl-F`: move o cursor um caractere para frente, complementando a navegação de caractere.

6. `Alt-B`: move o cursor uma palavra para trás, facilitando edição em palavras completas.

7. `Alt-F`: move o cursor uma palavra para frente, idem para avanço em palavras.

8. `Ctrl-U`: apaga tudo do cursor até o início da linha, limpando o comando rapidamente.

9. `Ctrl-K`: apaga tudo do cursor até o fim da linha, removendo o restante do comando.

10. `Ctrl-W`: apaga a palavra inteira antes do cursor, removendo token por token.

11. `Ctrl+C`: interrompe e encerra o programa em execução no terminal de forma graciosa.

12. `Ctrl+\`: força encerramento imediato do processo, com sinal quit mais forte.

13. `Ctrl+Z`: suspende o processo atual, colocando-o em segundo plano e retornando ao prompt.

14. `fg`: retoma o processo suspenso em primeiro plano, permitindo continuar execução interativa.

15. `bg`: retoma o processo suspenso em segundo plano, liberando o terminal para outros comandos.

16. `Ctrl+L`: limpa a tela do terminal, rolando o conteúdo anterior para cima e mantendo prompt no topo.

17. `Ctrl+Shift+C`: copia o texto selecionado no terminal para a área de transferência.

18. `Ctrl+Shift+V`: cola o texto da área de transferência no terminal, substituindo Ctrl+V.

19. `Seta para cima`: mostra o último comando digitado, permitindo reutilização e edição rápida.

20. `Seta para baixo`: mostra o próximo comando no histórico, navegando para frente ao editar.

21. `Ctrl+R`: busca no histórico de comandos, permitindo digitar parte do comando para encontrar.

22. `!!`: reexecuta o último comando, útil para repetir ações sem digitar tudo novamente.

23. `!$`: expande para o último argumento do último comando, evitando redigitação.

24. `! verbo`: reexecuta o último comando iniciado com aquele verbo, como `!git`.

25. `Ctrl+D`: encerra a sessão atual do shell, saindo do terminal ou do container.

26. `Ctrl+O`: após executar um comando, executa o anterior novamente, mantendo sucesso em loop.

27. `Ctrl+S`: trava a saída do terminal (stop), impedindo que texto novo apareça.

28. `Ctrl+Q`: desbloqueia a saída do terminal (start), permitindo que texto novo apareça novamente.

29. `Ctrl+G`: cancela busca de história iniciada pelo Ctrl+R, voltando ao prompt.

30. `Alt+.`: insere o último argumento do comando anterior, útil para repetir caminhos.

31. `history`: lista comandos recentes digitados, com números para reexecução via `!número`.

32. `!número`: reexecuta o comando com aquele número no histórico, permitindo retornar a ações antigas.

33. `*:., -`: combinação usada em bash para editar argumentos de comandos anteriores, como `!^` primeiro argumento.

34. `Ctrl+Alt+T`: atalho comum em desktop Linux para abrir rapidamente um novo terminal.

35. `Ctrl+Shift+T`: no terminal com abas, abre nova aba, organizando múltiplos contextos.

36. `Ctrl+Shift+W`: fecha a aba atual do terminal, limpando contexto não mais necessário.

37. `Ctrl+Shift+Q`: fecha a janela inteira do terminal, encerrando todas as abas.

38. `Ctrl+Shift+N`: cria nova janela de terminal, separando contextos visualmente.

39. `Ctrl+Shift+D`: divide o terminal em painéis, criando áreas horizontais ou verticais para multitarefa.

40. `Alt+1`, `Alt+2`, `Alt+3`: no terminal com painéis, muda o foco entre os painéis abertos.

41. `Ctrl+Alt+Setas`: no Windows Terminal, move o foco entre painéis divididos.

42. `Ctrl+Alt+-`: no Windows Terminal, divide o painel horizontalmente, criando nova área.

43. `Ctrl+Shift+Alt+-`: no Windows Terminal, divide o painel verticalmente.

44. `Shift+PageUp/PageDown`: rola o conteúdo do terminal para cima e para baixo, visualizando saída antiga.

45. `Ctrl+Home`: vai ao início do buffer do terminal, mostrando o conteúdo mais antigo.

46. `Ctrl+End`: vai ao final do buffer, voltando ao prompt atual.

47. ` Vincular perfil no Windows Terminal`: configurações de perfil permitem definir atalhos personalizados para abrir perfis específicos. [][web:229]

48. `Personalização de tema`: alterar cores, fontes e transparência do terminal melhora conforto visual e produtividade.

49. `Digite menos, use abreviações`: usar `cd -` para voltar ao diretório anterior economita tempo em navegação.

50. `Boas práticas de terminal`: usar abas, painéis, atalhos de teclado, histórico e autoComplete reduz tempo e esforço em tarefas diárias.
